## 🔧 Support Technique

### **Problèmes?**

1. **Interface ne charge pas**
   - Rafraîchir la page (Ctrl+R / Cmd+R)
   - Vider le cache navigateur
   - Essayer un autre navigateur

2. **Stats incorrectes**
   - Vérifier connexion internet
   - Se déconnecter/reconnecter
   - Contacter le support

3. **Responsive bizarre**
   - Vérifier zoom navigateur (100%)
   - Désactiver extensions navigateur
   - Tester sur autre device
